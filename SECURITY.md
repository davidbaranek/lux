# Security

Please report a vulnerability privately, not in a public issue. Use GitHub's private reporting:
the repository's **Security** tab, then **Report a vulnerability**. Include the steps to
reproduce it and the build you saw it in.

Lux has no releases yet, so only the latest `main` is supported.

Report a vulnerability in matrix-rust-sdk itself to the Matrix.org Foundation instead, as
described in its [security disclosure policy](https://matrix.org/security-disclosure-policy/).
